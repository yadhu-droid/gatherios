# Project Rules — Dearly (Birthday & Wedding App)

## Wedding Templates

- **No religious sub-themes**: Wedding templates are NOT split into Christian/Muslim/Hindu variants. Each template is a single, standalone design with one template ID.
- **Template 1** (`starry-template-1`, IDs 10/11/12) is the only exception — it was built with religious sub-themes. All future templates must NOT follow this pattern.
- **Each new wedding template** gets a single unique template ID (e.g., 13, 14, 15, etc.) and is a completely independent design.
- **Do not plan or implement** a new template until the user describes how it should look. Always wait for the user's design direction first.
